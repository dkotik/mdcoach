## Set the presentation time

The timer and its controls appear in the lower-right corner of a presentation. Move the pointer near the timer to reveal the controls. Enter a time in `MM:SS` format, such as `12:30`, and press Enter to apply it. You can also use **+1 min**, **+5 min**, or **−30 sec**; **Reset** restores the presentation's original timer duration.

The timer displays the remaining time. Click the timer, or focus it and press Enter or Space, to start or pause it manually.

## Automatic start and pause

The presentation timer starts automatically when you move from the first slide to another slide. It pauses when you return to the first slide. Its current duration, remaining time, and running state are saved in this browser for the presentation, so the timer can be restored when the presentation is reopened.

Toggle the presentation curtain with its menu button or the period (`.`) key. Opening the curtain pauses the timer; closing it starts the timer. This works in addition to slide navigation.

> **Tip:** On the first slide, open and then close the curtain to start the timer immediately. You do not need to switch to the second slide.
